# Account's *r*Bot

This repo is where Account's rBot functions, it is open source so users can see on how it works.
It is designed to work for 2 servers, 1 for public and 1 for private.
-# it is designed to only work for my steam deck.

# Features:

- Achievements.
- Auto-Updating from GIT.
- Automatic Upvote/Downvote on #COMMUNITY category, with forwarded message support.
- Custom Commands that uses Discord's built in `/` command.
- Sticky Roles.
- Storage handling (Bomb counter, etc.)
- User's Account Age checking.
